# Zoer - Emotional Recycling App

A Next.js application for emotional journaling with AI-powered emotion analysis and image generation.

## Features

- 🔐 User authentication (signup/login)
- 📝 Journal entries with emotion tracking
- 🤖 AI-powered emotion analysis
- 🎨 AI image generation from emotions
- 📤 File upload functionality
- 📊 Dashboard with emotional insights

## Tech Stack

- **Framework:** Next.js 14 (React/TypeScript)
- **Database:** PostgreSQL
- **AI:** OpenAI API
- **Styling:** Tailwind CSS
- **Authentication:** JWT
